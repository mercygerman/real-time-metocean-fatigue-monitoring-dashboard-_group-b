# Real-Time Metocean Fatigue Monitoring Dashboard _Group B

Build a simulated real-time fatigue monitoring system that ingests hourly metocean readings, computes wave spectra, estimates hourly fatigue damage, accumulates total damage, and generates alerts when damage thresholds are exceeded. The system should produce an auto-updating dashboard showing current sea state, hourly damage rate, cumulative damage trajectory with remaining life projection, and alert history.
